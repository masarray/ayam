# Truck Horn Kind Routing

Heavy traffic vehicles now use a dedicated low `Thottt` horn instead of the passenger-car `Diiiin` horn.

## Heavy-vehicle kinds
- bus
- boxTruck
- articulatedTruck
- dumpTruck
- tankerTruck
- containerTruck

## Behavior
- Passenger cars still use `carHorn()`.
- Heavy vehicles use `truckHorn()`.
- The warning trigger remains based on the vehicle front approaching the chicken on the same traffic row.
