# Opening Flow, Train Nose, Button Style, and Line Stability Audit

## Opening flow
The first gameplay rows were explicitly curated to avoid unrealistic road-to-road adjacency.

Sequence:
- rows 0-3: start grass / trees
- rows 4-5: 2-lane road
- row 6: grass / trees
- row 7: river
- row 8: grass / trees
- rows 9-12: 4-lane road
- row 13+: normal generator resumes

## Bullet train shape
The high-speed train head length was extended and the nose/tail taper was stretched further so the silhouette reads more like a bullet/pill instead of a short nose.

## Arrow controls
The visible arrow button was slimmed back down while the larger hit area remained in place.

## Road marking shimmer
The road lines were thickened again:
- white divider: 0.74
- white edge: 0.94
- yellow line: 0.78
