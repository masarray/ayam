# Train Horn and Quiz Reward UI Fix

## Train horn
The train horn is now tied to the locomotive front edge, not the train body center. Each train can horn once per approach, and the state resets only after the train wraps around for a new pass.

## Revive quiz layout
The redundant `Revive Quiz` chip/title/subtitle block was removed from the active quiz screen to leave more space for the question and answers.

## Correct answer reward
Correct feedback now reads `Yey Benar! +5` with the uploaded coin SVG shown inline.
